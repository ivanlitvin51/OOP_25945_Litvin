================================================================================
          СТРУКТУРА ПОЭТАПНОГО ВЫПОЛНЕНИЯ ЗАДАНИЯ №5 (НГУ ООП)
================================================================================

В этой папке сохранены контрольные этапы развития проекта по пунктам задания:

- step_5_1/
    Задание 5.I: Все файлы проекта (hypo.hpp, hypo.cpp, hypo_mod.hpp, hypo_mod.cpp,
    main.cpp) и CMakeLists.txt находятся в одной директории. Библиотека для типа int
    собирается как статическая (STATIC).

- step_5_2/
    Задание 5.II: Библиотека функций вынесена в отдельную поддиректорию hypo_lib/
    со своим CMakeLists.txt, подключена в корневом CMake через add_subdirectory.

- В корневой папке hw_05/ находится финальная завершенная версия (5.V),
  объединяющая все требования:
    * Библиотека в поддиректории hypo_lib/ (Задание 5.II)
    * Модульные тесты Google Test в папке tests/ (Задание 5.III)
    * Опция CMake BUILD_TESTS (ON/OFF) (Задание 5.IV)
    * Шаблонные функции (template <typename T>) и INTERFACE библиотека (Задание 5.V)
